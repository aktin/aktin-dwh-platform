# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub:
https://github.com/{{REPO_SLUG}}/security/advisories/new

Include the affected version, steps to reproduce and the impact you expect.
You get an acknowledgement within a week. Fixes are published as a new release
together with a GitHub Security Advisory, and you are credited unless you
prefer not to be.
